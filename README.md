# Virus-tracker static demo

This repository contains only the static GitHub Pages snapshot of Virus-tracker.
The full source code is kept in a private repository.

- Live demo: https://weixuphd.github.io/virus-tracker/
- Static snapshot: dashboards, event pages, 100-day history, 30-day digests, AI-READY reports and data downloads.
- Collection, LLM summarization, manual runs, filters and cross-institution queries require the backend and are not available in this static demo.

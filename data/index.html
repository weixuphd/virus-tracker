快速使用

JSONL 每行一个事件，可直接导入向量数据库或构造训练样本。

curl -s /virus-tracker/downloads/events.jsonl \
  > events.jsonl

python - <<'PY'
import json, itertools
records = [json.loads(line) for line in open("events.jsonl")]
for r in itertools.islice((x for x in records if x["severity"]["label"] in {"high", "critical"}), 5):
    print(r["event"]["headline_zh"], r["severity"]["score"])
PY

RAG / embedding

使用 embedding_text 做向量化；用 source.url 与 provenance.content_hash 回溯原文。

结构化筛选

按 pathogens[].name、hosts、locations、severity.label 过滤；不要只依赖摘要。
